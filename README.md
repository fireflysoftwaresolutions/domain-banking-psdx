# Firefly OpenPlatform - Domain - PSD2

Developed by the Firefly Software Foundation. [dev@fireflysoftware.io](mailto:dev@fireflysoftware.io)

[Website](https://fireflysoftware.io/) · [OpenPlatform](https://fireflysoftware.io/openplatform/) · [Module catalogue](https://fireflysoftware.io/openplatform/modules/)

Reads a PSD2 consent from core-banking-psdx through core-banking-psdx-sdk (`ConsentManagementApi.getConsent`).

`firefly.psdx.consent.adapter` defaults to `sandbox`. `core` selects the SDK adapter. The sandbox returns one sample consent and does not open a socket.
